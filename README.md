# TODO List Application
TODO List Application is a simple and practical task management project built using Java, Maven, and a relational database. The application lets users create, read, update, and delete tasks stored in a database, demonstrating core CRUD functionality, database interaction, and backend application structure using Java. This project showcases essential skills in Java development, Maven dependency management, and database integration.

# Features
Add new tasks to your TODO list
View all saved tasks
Update existing tasks
Delete completed or unwanted tasks
Database-backed persistence for task storage

# Technologies Used
Java – Core programming language
Maven – Build tool and dependency management
Database (SQL) – Persistent storage for TODO items
JDBC / ORM – For connecting and interacting with the database

# Overview
This project demonstrates how to build a backend application in Java that interacts with a database to manage user tasks. It highlights foundational concepts such as database connectivity, query execution, and structured project setup using Maven
